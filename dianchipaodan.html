                      使用帮助

                      一份给新手的图文说明

                      遇到不会用的地方，展开对应小节看看就好。

                      🚀 快速开始

                      首次打开会自动建一块空白「我的电池」，不用预先填示例数据，记的第一笔就是你的真实数据。

                      • 从底部（手机）/左侧（电脑）的「📝 记录」开始记第一笔：充电、里程、跑单、奖励、支出、记账。
                      • 两种打开方式：① 直接双击 index.html 用浏览器打开；② 部署到固定网址（GitHub Pages 等），数据更稳、换设备也能用。
                      📝 六种记录怎么填
                      • 🔋 充电：填起止电量 %、度数、花费、续航、时长；单价和真实耗电会自动算。
                      • 🚗 里程：记当天骑了多少公里（跑单或不跑单都记），用于估算电量还能撑多久。
                      • 🛵 跑单：按「日期 + 平台」加单量和收入，一天可加多个平台；保险费按「每天每平台」只扣一次；可填工作时长，用来算平均时薪。
                      • 💸 其他支出：维修保养、跑单罚单，金额计入成本。
                      • 🎁 奖励：满勤奖、冲单奖等，直接算进收入。
                      • 💰 记账：吃饭、房租、烟水这类生活开支，和跑单成本分开算，不进净利润。填法见下方「💰 记账与生活账」。

                      每类记录下方都有「近期记录」列表，点「编辑」回填修改；点「删除」后会弹出提示，5 秒内点「撤销」可恢复。

                      🛵 跑单与保险费
                      • 保险费 每天每平台只扣一次（如 京东秒送 ¥3、美团众包 ¥2.5、淘宝闪购 ¥2.5、货拉拉 ¥0）。
                      • 同一天同一平台跑几单，只在首单扣，不会重复。
                      • 费率可在「⚙️ 我的 → 🛵 平台与保险费」里改，改后历史统计按新费率重算。
                      • 老数据用英文键（jd/meituan 等）记录的会自动归并到对应平台，不会重复统计。
                      🎁 活动奖励算在哪
                      • 奖励金额计入「跑单收入」和「净利润」，奖励本身不扣保险费。
                      • 数据总览里有「活动奖励(周期)」和「今日 / 当日奖励」两项单独展示。
                      • 净利润已含奖励，会标注「（含奖励）」。
                      • 奖励指定平台时并入对应平台分布；不指定则以金色单独成条。
                      🔋 电池与提醒
                      • 支持多块电池（铅酸 / 石墨烯 / 锂电等），各自独立记录，可随时切换。
                      • 电量自动测算：以最近一次充电的「结束电量 + 满电续航」为基准，自动扣减之后每天登记的里程，得到当前剩余电量；你每天记的里程越多，电量估算越准。
                      • 手动修正：在「⚙️ 我的 → 电池管理 → 编辑」里改「当前电量」，系统会把它作为新的基准点，后续里程从这里开始扣。
                      • 满电续航：在「⚙️ 我的 → 电池管理 → 编辑」里手动填一次即可，系统会拿它做电量估算与衰减提醒。
                      • 📉 衰减趋势：把每次充电填过的续航按日期连成折线，线往下走就是电池在衰减；首尾差 ≥10% 会转成警示色并提醒「要不要换电池」。所以每次充满顺手填一下「满电续航」，这块才有数据。
                      • 电量环显示当前电量 %；智能提醒结合电量 + 近期骑行里程，估算「还能跑多少公里 / 大约还能用几天」。
                      • 桌面通知：在电池页或「我的」勾选「开启桌面提醒」，电量过低或久未充电时弹窗。需以 https 或已安装方式打开（file:// 下会自动置灰，这是浏览器限制）。
                      • 顶部已不显示电池卡：电池的电量环、续航估算、低电提醒都在「🛵 电池」页（见上方）；页面顶部居中改为常驻「今日数据」条，见下方数据总览。
                      📊 看懂数据总览
                      • 顶部切换时间范围：总 / 今年 / 选月（可左右翻月）/ 某天（精确到某日）/ 区间（自选起止日期），所有统计卡和图表同步变化。「区间」适合看「上个月 5 号到 20 号」这种跨不了整月的账，起止日期记在本机，下次打开还在。
                      • 净利润 = 收入 − 总成本，其中总成本 = 电费 + 平台保险 + 维修保养 + 罚单 + 固定成本(周期摊) + 车辆折旧(周期摊)；每一项都在「成本」区单独列出，口径和手机 App 完全一致。
                      • 📈 每日收入趋势：把当前范围里每天的「跑单收入 + 奖励」连成折线，只画有收入的天（休息日不补零，补了会被压成一条平线）；纵轴从 0 起，方便横向比高低。
                      • 平台分布按各平台品牌色展示收入占比；奖励金色单独条。
                      • 底部可一键导出当前范围的 Excel(.xls) 报表或 PDF 报表。
                      • 顶部「今日数据」条：页面顶部居中常驻显示今天的「单量 / 收入 / 净利 / 电费」四项，点一下直接跳到本页。收入 = 跑单收入 + 活动奖励；净利 = 当日收入 − 当日全部成本（含按天摊的固定成本与折旧，所以休息日会是负数，那不是算错，是租金照样在扣）；电费 = 今天充电花费。
                      📜 历史记录
                      • 左侧/底部导航「📜 历史」把充电、里程、跑单、奖励、其他支出五类记录按时间合并成一条时间线。
                      • 可按类型筛选，也可以按关键字、日期区间、平台、电池搜索，找到某条记录。
                      • 点某条记录可直接编辑或删除；删除同样支持 5 秒内撤销。
                      📑 经营报告
                      • 在「📊 数据总览 → 导出报表」里选月份，生成正式月度经营报告。
                      • 报告包含核心指标：总收入、净利润、总成本、利润率、固定成本、车辆折旧、工作时长、总订单、总里程、平均时薪、平均每单、平均每公里 —— 与数据总览同一套口径。
                      • 下方还有 6 张图表：收入趋势、平台分布、电池消耗、充电成本、里程、成本构成（成本构成里含固定成本与车辆折旧）；底部还会显示「本月比上月收入」环比；可一键导出 Excel 或 PDF。
                      💰 记账与生活账
                      • 「📝 记录 → 💰 记账」记的是生活收支（吃饭、房租、烟水、工资…），和跑单的充电 / 保险 / 维修 / 罚单分开算，不进「净利润」—— 免得生活花销把跑单的账搞乱。
                      • 每笔填日期、收 / 支、金额、分类、账户（可选）与备注（可选）；分类和账户都能自己加，填过一次以后下拉里就有了。
                      • 「📊 记账小结」显示本月收入 / 支出 / 结余；想管住手就去「⚙️ 我的 → 🧮 成本与目标」填「记账月预算」，小结会告诉你这个月还剩多少能花。
                      • 点某笔可编辑或删除，删除后 5 秒内可撤销；也能单独导出成「导出记账 CSV」。
                      🪪 证件到期提醒
                      • 在「⚙️ 我的 → 🪪 证件到期提醒」登记证件名和到期日（驾驶证、健康证、车辆年检、保险单…），下面按剩余天数排序显示。
                      • 剩余天数不存库、每次打开实时算，所以不会出现「昨天还显示 30 天」这种假数字。
                      • 剩 7 天内标黄、当天或已过期标红，一眼看出哪个最急。
                      • 提前提醒天数可设 1~365 天；也能单独导出成「导出证件 CSV」。
                      🧮 成本与目标（净利润是怎么来的）
                      • 在「⚙️ 我的 → 🧮 成本与目标」填租车费 / 电池租金 / 其他月租（合起来是每月固定成本），再填车价和打算用多少个月（自动算车辆折旧 / 月）。
                      • 固定成本和折旧都是按月摊、含首尾两天（30 天算 1 个月）。所以看「某天」时只摊到约 1/30 —— 休息日算出负的净利是正常的，租金不会因为今天没跑就不收。
                      • 净利润 = 收入 −（电费 + 平台保险 + 维修保养 + 罚单 + 固定成本 + 车辆折旧）。「日均净利 / 每公里净利 / 今日净利」全部由这个数推出来，口径一致。
                      • 这里还能设「默认骑手」和日 / 周 / 月收入目标；这些设置都会随整包 JSON 一起备份。
                      💾 备份与导出
                      • 导出整包 JSON：电池 + 充电 + 里程 + 跑单 + 奖励 + 支出 + 记账 + 证件，再加上平台保险费率与「成本与目标」设置，一起导出，换机或重装时导入恢复。文件格式和手机 App 的备份互相兼容，两边可以互导。
                      • 数据存在哪：数据存在你打开这个网页的浏览器里，不是电脑文件夹；「我的」页顶部状态条和这里的「导出整包 JSON」都能把它下载成真实文件。
                      • 导出 CSV：跑单 / 里程 / 奖励 / 充电 / 维修罚单 / 记账 / 证件 各自独立导出，文件带 BOM，Excel / WPS 打开中文不乱码，方便做账报税。
                      • 每日备份提醒：每次更新数据后，如果今天还没导出过 JSON，页面底部会弹一个提示卡，点「立即备份」直接下载整包 JSON，点 × 则当天不再打扰。即使已开启 GitHub / Gist 同步，也建议偶尔导一份本地文件做兜底（换机 / 重装 / 云端被覆盖时能救回）。
                      💸 其他支出（维修保养 / 罚单）
                      • 在「📝 记一笔 → 💸 其他支出」里登记两类花销：🛠 维修保养（保养 / 维修 / 换电池 / 换轮胎 / 换刹车 / 其他）和 🚨 跑单罚单（罚单 / 闯红灯 / 超速 / 逆行 / 超时 / 其他）。
                      • 点「支出类型」切换后，下面的「项目 / 类型」和「关联平台」会自动跟着变；罚单需选关联平台（哪个平台派单时吃的罚单），维修保养可不填。
                      • 类别支持自定义：「项目 / 类型」是输入框，既能在下拉里选预设项，也能直接打字填任意内容（如「改装」「补漆」「违停申诉」）。你填过的新类别会被自动记住，下次直接在下拉里选，不用重复输入。
                      • 金额、日期、备注都记全，方便日后回看花在哪。
                      • 数据总览「成本」区有 维修保养(周期) 和 跑单罚单(周期) 两项总额，随上方时间范围（总 / 今年 / 选月 / 某天 / 区间）一起变化。
                      • Excel / PDF 报表和「我的 → 导出维修罚单 CSV」都包含这项支出。
                      ☁️ GitHub 同步（可选）
                      • 把数据同步到你自己的仓库，换电脑 / 换网址都能拉回。
                      • 在「⚙️ 我的 → ☁️ GitHub 同步」填 Token（仅存本机）、仓库名；Token 输入框右侧有 👁 小眼睛，可切换显示/隐藏，方便核对。
                      • 公开仓库建议保持「推送数据文件」关闭，只同步 index.html + README，保护隐私。
                      • 勾选「同步源代码」可把网页和说明一并推送。
                      📝 Gist 同步（可选）
                      • 不想建仓库也能同步：用 GitHub Gist，只要一个有 gist 权限的 Token（和上方 GitHub 同步的 token 可相同也可不同）。
                      • 在「⚙️ 我的 → 📝 Gist 同步」填 Token；Token 输入框右侧有 👁 小眼睛，可切换显示/隐藏。Gist ID 留空，首次点「推送」会自动创建并记住 ID，以后都更新这一个。
                      • 「公开 Gist」默认不勾（私有，只有你能看），真实数据请勿勾选公开。
                      • 勾选「启用」+「自动同步」后：本地改动约 1.2 秒自动推上去，远程有改动每 10 秒自动拉回合并，多设备实时一致。
                      • 点「测试连接」先验证 Token 有效，再「推送」即可。
                      🎨 外观与主题

                      「⚙️ 我的 → 外观」可在 浅色 / 深色 / 跟随系统 间切换；跟随系统会随系统偏好自动变。

                      🔒 隐私与安全
                      • 数据默认只存在你打开这个网页的浏览器里，不是电脑上的某个文件夹，也不会上传任何第三方服务器。
                      • Token 只存本机，不会写进推送的数据文件。
                      • 提醒：WorkBuddy / IDE 预览每次端口会变，等于换了网址，浏览器里的旧数据就读不到了；建议 file:// 双击或部署到固定网址打开。想拿到能复制/换机的真实文件，用「导出整包 JSON」。
                      ❓ 常见问题
                      • 桌面通知在 file:// 下用不了？这是浏览器限制，部署到 https 或安装到桌面即可。
                      • 记错了能改吗？每类记录下方「近期记录」列表里点「编辑」回填修改；点「删除」后会弹出提示，5 秒内点「撤销」可恢复，不用怕误删。
                      • 多电池怎么切换？「🔋 电池」页或「我的」里选当前使用的电池。
