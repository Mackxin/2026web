                🚀 快速开始

                首次打开会自动建一块空白「我的电池」，不用预先填示例数据，记的第一笔就是你的真实数据。

                • 从底部（手机）/左侧（电脑）的「📝 记录」开始记第一笔：充电、里程、跑单、奖励。
                • 两种打开方式：① 直接双击 index.html 用浏览器打开；② 部署到固定网址（GitHub Pages 等），数据更稳、换设备也能用。
                📝 四种记录怎么填
                • 🔋 充电：填起止电量 %、度数、花费、续航、时长；单价和真实耗电会自动算。
                • 🚗 里程：记当天骑了多少公里（跑单或不跑单都记），用于估算电量还能撑多久。
                • 🛵 跑单：按「日期 + 平台」加单量和收入，一天可加多个平台；保险费按「每天每平台」只扣一次。
                • 🎁 奖励：满勤奖、冲单奖等，直接算进收入。

                每类记录下方都有「近期记录」列表，点「编辑」把整笔回填修改，点「删除」二次确认后移除。

                🛵 跑单与保险费
                • 保险费 每天每平台只扣一次（如 京东秒送 ¥3、美团众包 ¥2.5、淘宝闪购 ¥2.5、货拉拉 ¥0）。
                • 同一天同一平台跑几单，只在首单扣，不会重复。
                • 费率可在「⚙️ 我的 → 🛵 平台与保险费」里改，改后历史统计按新费率重算。
                • 老数据用英文键（jd/meituan 等）记录的会自动归并到对应平台，不会重复统计。
                🎁 活动奖励算在哪
                • 奖励金额计入「跑单收入」和「净收入」，不扣保险费。
                • 数据总览里有「活动奖励(周期)」和「今日 / 当日奖励」两项单独展示。
                • 净收入已含奖励，会标注「（含奖励）」。
                • 奖励指定平台时并入对应平台分布；不指定则以金色单独成条。
                🔋 电池与提醒
                • 支持多块电池（铅酸 / 石墨烯 / 锂电等），各自独立记录，可随时切换。
                • 电量自动测算：以最近一次充电的「结束电量 + 满电续航」为基准，自动扣减之后每天登记的里程，得到当前剩余电量；你每天记的里程越多，电量估算越准。
                • 手动修正：在「⚙️ 我的 → 电池管理 → 编辑」里改「当前电量」，系统会把它作为新的基准点，后续里程从这里开始扣。
                • 满电续航：优先取最近一次充电记录填的「充满后续航」；如果还没记过充电，可在电池编辑里手动填一个。
                • 电量环显示当前电量 %；智能提醒结合电量 + 近期骑行里程，估算「还能跑多少公里 / 大约还能用几天」。
                • 桌面通知：在电池页或「我的」勾选「开启桌面提醒」，电量过低或久未充电时弹窗。需以 https 或已安装方式打开（file:// 下会自动置灰，这是浏览器限制）。
                • 右上角电池信息卡：页面右上角常驻显示当前电池「🛵 电池名 · 电量% + 状态点」。状态点颜色：绿色=电量充足、黄色=偏低（<40%）、红色=极低（<20%）、蓝色脉冲=今天有充电且尚未充满。点一下卡片可直接跳到「电池」页。
                📊 看懂数据总览
                • 顶部切换时间范围：总 / 今年 / 选月（可左右翻月）/ 某天（精确到某日），所有统计卡和图表同步变化。
                • 净收入 = 收入 − 保险费（不含电费）；「总电费」单独列出。
                • 平台分布按各平台品牌色展示收入占比；奖励金色单独条。
                • 底部可一键导出当前范围的 Excel(.xls) 报表或 PDF 报表。
                💾 备份与导出
                • 导出整包 JSON：电池 + 充电 + 里程 + 跑单 + 奖励全部数据，换机或重装时导入恢复。
                • 导出 CSV：跑单 / 里程 / 奖励 / 充电 / 维修罚单 各自独立导出，文件带 BOM，Excel / WPS 打开中文不乱码，方便做账报税。
                • 每日备份提醒：每次更新数据后，如果今天还没导出过 JSON，页面底部会弹一个提示卡，点「立即备份」直接下载整包 JSON，点 × 则当天不再打扰。即使已开启 GitHub / Gist 同步，也建议偶尔导一份本地文件做兜底（换机 / 重装 / 云端被覆盖时能救回）。
                💸 其他支出（维修保养 / 罚单）
                • 在「📝 记一笔 → 💸 其他支出」里登记两类花销：🛠 维修保养（保养 / 维修 / 换电池 / 换轮胎 / 换刹车 / 其他）和 🚨 跑单罚单（罚单 / 闯红灯 / 超速 / 逆行 / 超时 / 其他）。
                • 点「支出类型」切换后，下面的「项目 / 类型」和「关联平台」会自动跟着变；罚单需选关联平台（哪个平台派单时吃的罚单），维修保养可不填。
                • 类别支持自定义：「项目 / 类型」是输入框，既能在下拉里选预设项，也能直接打字填任意内容（如「改装」「补漆」「违停申诉」）。你填过的新类别会被自动记住，下次直接在下拉里选，不用重复输入。
                • 金额、日期、备注都记全，方便日后回看花在哪。
                • 数据总览「成本」区有 维修保养(周期) 和 跑单罚单(周期) 两项总额，随上方时间范围（总 / 今年 / 选月 / 某天）一起变化。
                • Excel / PDF 报表和「我的 → 导出维修罚单 CSV」都包含这项支出。
                ☁️ GitHub 同步（可选）
                • 把数据同步到你自己的仓库，换电脑 / 换网址都能拉回。
                • 在「⚙️ 我的 → ☁️ GitHub 同步」填 Token（仅存本机）、仓库名，点测试连接 → 推送。
                • 公开仓库建议保持「推送数据文件」关闭，只同步 index.html + README，保护隐私。
                • 勾选「同步源代码」可把网页和说明一并推送。
                📝 Gist 同步（可选）
                • 不想建仓库也能同步：用 GitHub Gist，只要一个有 gist 权限的 Token（和上方 GitHub 同步的 token 可相同也可不同）。
                • 在「⚙️ 我的 → 📝 Gist 同步」填 Token；Gist ID 留空，首次点「推送」会自动创建并记住 ID，以后都更新这一个。
                • 「公开 Gist」默认不勾（私有，只有你能看），真实数据请勿勾选公开。
                • 勾选「启用」+「自动同步」后：本地改动约 1.2 秒自动推上去，远程有改动每 10 秒自动拉回合并，多设备实时一致。
                • 点「测试连接」先验证 Token 有效，再「推送」即可。
                🎨 外观与主题

                「⚙️ 我的 → 外观」可在 浅色 / 深色 / 跟随系统 间切换；跟随系统会随系统偏好自动变。

                🔒 隐私与安全
                • 数据默认只存在你的浏览器 localStorage，不上传任何第三方。
                • Token 只存本机，不会写进推送的数据文件。
                • 提醒：WorkBuddy / IDE 预览每次端口会变，等于换了网址，localStorage 读不到旧数据；建议 file:// 双击或部署到固定网址。
                ❓ 常见问题
                • 桌面通知在 file:// 下用不了？这是浏览器限制，部署到 https 或安装到桌面即可。
                • 记错了能改吗？每类记录下方「近期记录」列表里点「编辑」回填修改、点「删除」二次确认移除。
                • 多电池怎么切换？「🔋 电池」页或「我的」里选当前使用的电池。
